【対CPU】剣を持った敵(25%は銃を持った敵)をすべて倒そう
・敵を全滅させると次のウェーブへ進み、HPが1回復します。2ウェーブごとにボス戦(迷路なし)。制限時間は5分、HPは5。通常の敵はHP2で、歩くのは速めです。
・ボス戦: 1回目は銃を撃つボス(撃つ速さはその時の体力で変わる)、2回目は左右に動きジャンプしながら殴ってくるボス、3回目はその2人が同時に出てHPは各3分の2、4回目以降はどちらかがランダムで出てボス戦ごとにHPが1.5倍になります。
・カメラを持っている間はFPS視点で、銃は使えず、左クリックのナイフで敵に密着して戦います(移動速度は半分)。カメラを置くと銃が使えます(左クリック)。右クリックの照準レーザーは1秒出て再充填に2秒かかります(ダメージなし)。
・置いたカメラは5秒後から曇り始め、15秒で真っ白になると自動で回収されます。拾うと曇りが取れます。
・迷路はウェーブごとに作り直され(そのとき球も消える)、ボス戦以外のウェーブでは20秒に1個、半透明の球が出て、触れるとランダムで1つ効果を得る: HPを1回復 / 攻撃力2倍(15秒) / 移動速度1.5倍(10秒) / カメラが曇らない(30秒) / アーマー(HP2分・20秒) / 10秒間ミニマップを右上に出して敵の位置が分かる / 10秒間敵に見つからない / ランダムな場所にテレポート / 1分間弾が箱を貫通する
・攻撃を受けると0.25秒間、赤く光ります(倒されるときを除く)。
【対人】ほかのプレイヤーと戦おう
・名前(10文字まで)を入れて、部屋を作る(6桁コードが出る)か、コードを入れて部屋に参加する。2人以上でホストが開始。HPは10。
・勝敗: 全員を倒すか、10分たつと終了。時間切れはスコア = 残りHP + 与えたダメージ ÷ 2が最大の人の勝ち。
・ほかのプレイヤーを倒すと、30秒間、自分の攻撃力が1.5倍。倒されると、全員の画面の左下に5秒間「(倒された人)は、(倒した人)に倒された」と出ます。
・F: フラッシュ(カメラを持っているとき、1分に1回)。使った人のおなか側を画面に入れた相手は2秒間まぶしくなる(顔も白くなる)。窓は通り抜けます(弾は通りません)。
・Tab: メッセージ画面(25文字まで、Enterで5秒に1回送れる。左下に送った人の名前が服の色で出る)。メッセージ画面では動けず撃てません。
・T: タイム(各プレイヤー1試合に1回)。全員の操作と10分のタイマーが止まり、画面が薄暗くなる。もう一度Tを押す(タイムにした人のみ)と3秒のカウントダウンのあと再開。タイム中はメッセージを間隔の制限なしで送れます。
・置いたカメラの黄色い部分は、その人の服の色になります。カメラはQで蹴って動かせます(ほかの人の置いたカメラも蹴れて、その人の画面もずれます)。
・球: 30秒に1個、マップのどこかに半透明の球が出る(プレイヤーの近くには出ない)。触れるとランダムで1つ効果を得る: HPを1回復 / 攻撃力2倍(15秒) / 移動速度1.5倍(10秒) / カメラが曇らない(30秒) / アーマー(HP2分・20秒) / 体の横幅が半分(60秒) / 相手のカメラ視点の移動を遅くする(15秒) / 相手のカメラを曇らせる / フラッシュ無効(1分) / 相手のカメラを強制設置 / 相手の位置をミニマップに表示(5秒) / ランダムな場所にテレポート / 1分間弾が箱を貫通する
・攻撃を受けると0.25秒間、キャラクターが赤く光る(倒されるときを除く)。名前の色: 黄色は能力アップ中、青色はダウンさせられている間。ミニマップには迷路と自分の位置、球が出る。
